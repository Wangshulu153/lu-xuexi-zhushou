# 输出规范与交付前检查单

## 通用要求

- 内容必须来自真实梳理结果，禁止占位符、示例性假数据。
- 所有关键结论要么带来源编号，要么标注“模型固有知识，未经联网验证”。
- 引用必须真实可溯：标题、来源、URL、检索日期；禁止编造链接和文献。
- 篇幅与内容深度匹配：入门内容精炼轻快，专业内容可以长但层次分明。
- 涉及争议话题呈现多方观点并注明立场来源，不输出个人倾向。
- 单页/单笔记聚焦一个明确主题；主题过大时建议分次学习。

## HTML 学习页面检查单

- 单文件：CSS 与 JS 全部内联，除可选字体外无外部资源，断网可完整学习。
- 结构：封面区（标题、导语、学习目标）、锚点目录或粘性侧边栏、分章节正文、术语卡/提示框/警告框、自测区、来源引用区、页脚。
- 知识脉络图：用纯 HTML/CSS（flex/grid 嵌套）绘制，不依赖外部库。
- 自测题：原生 JS 实现“点击选项，即时反馈对错并展开解析”；默认隐藏答案。
- 响应式：手机与桌面浏览器均正常显示；中文字体栈为 PingFang SC、Microsoft YaHei、Noto Sans SC、sans-serif。
- 来源区标注哪些内容经联网检索验证、哪些是模型固有知识；页脚含生成日期和延伸学习建议。

## Markdown 学习笔记检查单

- 结构化标题与学习目标开头。
- 关键词表或关键词清单紧跟标题区。
- 正文按知识脉络分章节，术语首次出现即解释。
- 对比、流程、时间线优先用表格或列表。
- 自测题含题目、答案与解析（答案可用折叠或文末分区）。
- 文末有来源列表、未验证标注和延伸阅读。

## 活人感模式检查单

- 只改表达层，事实和来源未变。
- 复杂概念先有共同生活隐喻或大白话，再给正式定义。
- 通读一遍没有 AI 八股腔、金句腔、永远中立腔。
- 没有编造细节来“显得具体”。
- 用户没有要求活人感时，未误用本层。

## 交付后

- 提供 2-4 个后续选项：深入章节、增加自测题、调整风格、转换 HTML/Markdown 格式。
- 如平台支持，直接落盘文件并给出路径；否则提供完整代码。
