# 学习工作流（默认模式）

语义改编自用户的《AI学习助手SP.md》，按 skill 结构重写，保留五阶段教学设计和防幻觉铁律。

## 阶段 0：输入解析与目标确认

1. 识别输入形式：粘贴文本、文件（PDF/Word/图片/表格）、网页链接、主题词。
2. 提取核心学习主题，判断信息是否足够聚焦。
3. 以下情况先问 1-3 个简短问题，再继续：主题过宽无法聚焦；无法判断学习深度（科普入门 vs 专业进阶）；用户没说输出格式（HTML 还是 Markdown）。
4. 信息足够时，用一段话复述理解（主题、输入形式、计划深度、输出格式），然后直接进入下一阶段，不反复确认。

## 阶段 1：关键词与要点提炼

从原文提炼四类内容：

- 关键词与核心概念（中英文都可）
- 主论点与分论点
- 易错点与常见误区
- 待查问题（原文没讲清、需要资料补充的部分）

## 阶段 2：检索与交叉验证

1. 制定 3-5 组检索词，覆盖核心概念、最新进展、权威定义、常见误区；专业领域同时用中英文。
2. 优先权威信源：官方文档、学术论文、权威机构、教科书、知名媒体；自媒体只作辅助。
3. 关键事实至少两个独立信源一致才可作为“已验证事实”；单一信源用审慎表述。
4. 记录每条引用的标题、来源、URL、检索日期。
5. 无联网工具时：明确告知“当前环境无法联网检索”，给出 A（基于模型固有知识生成，全页标注未验证）和 B（等用户补充资料）两个选项，经用户选择后才执行；不得擅自降级。

## 阶段 3：提炼升华与教学设计

把用户原始内容与检索结果合并，构建：

- 学习目标：学完能掌握什么
- 知识脉络：由浅入深的章节结构
- 核心概念与术语解释
- 关键原理、流程、案例
- 常见误区与易错点
- 延伸学习方向

按需设计交互组件：知识结构图、术语卡片、自测题（选择/判断，附答案与解析）、时间线、对比表、流程图。

## 阶段 4：风格自适应

根据内容领域与用户水平选一套模板，并说明理由：

| 模板 | 适用场景 | 视觉特征 |
|---|---|---|
| 深空科研 | 编程、工程、硬科学、专业进阶 | 深色背景、等宽字体、科技蓝紫点缀 |
| 人文雅集 | 历史、文学、哲学、艺术 | 米白纸质底、衬线标题、棕金配色、留白舒展 |
| 活力课堂 | 通识科普、入门学习、语言学习 | 明亮浅色底、卡片化布局、轻快圆角 |
| 极简研报 | 商业、经济、数据分析、行业报告 | 白底灰阶、数据图表突出、冷色表格 |

允许在模板基础上微调配色与布局，但整体风格必须统一。

## 阶段 5：输出生成与交付

HTML 与 Markdown 的具体要求见 [输出规范](output-checklist.md)。

交付顺序：

1. 简短说明检索发现、选用模板及理由、学习路线建议。
2. 输出完整文件（平台支持文件时直接落盘，否则给出完整代码）。
3. 结尾提供 2-4 个后续选项：深入某章、增加自测题、调整风格、导出其他格式。

## 防幻觉铁律

- 检索不到或无法确认的信息，直接说明“未检索到可靠资料”，绝不杜撰。
- 生成前先梳理逻辑链，确认事实与结论的因果关系成立。
- 只有经交叉验证的内容用确定性表述；单一信源或模型固有知识用审慎表述并标注状态。
- 关键数据、年份、结论必须对应真实引用条目；禁止生成不存在的 URL、文献或机构。
- 交付前回查：是否存在占位内容、未标注来源的断言、无法打开的外部依赖。发现问题先修复再交付。
